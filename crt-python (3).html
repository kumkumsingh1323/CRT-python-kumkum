1. Largest of Two Numbers

This program accepts two numbers from the user and prints the largest number using if-else.

a=int(input("Enter First Number: "))
b=int(input("Enter Second Number: "))
if a>b:
    print("Largest =",a)
else:
    print("Largest =",b)

2. Assign Grades Based on Marks

This program assigns grades according to the marks entered by the user.

marks=int(input("Enter Marks: "))
if marks>=90:
    print("Grade A")
elif marks>=80:
    print("Grade B")
elif marks>=70:
    print("Grade C")
elif marks>=60:
    print("Grade D")

3. Leap Year

This program checks whether a year is a leap year.

year=int(input("Enter Year: "))
if year%4==0:
    print("Leap Year")
else:
    print("Not Leap Year")

4. Electricity Bill Using Slab Rates

This program calculates the electricity bill using slab rates.

units=int(input("Enter Units: "))
if units<=100:
    bill=units*1.5
elif units<=200:
    bill=(100*1.5)+(units-100)*2.5
else:
    bill=(100*1.5)+(100*2.5)+(units-200)*4
print("Electricity Bill =",bill)

5. FizzBuzz

Commonly asked at Amazon, Microsoft, Adobe, Zoho & TCS Digital. Checks a number for divisibility by 3 and 5 and prints Fizz, Buzz, or FizzBuzz.

n=int(input("Enter Number: "))
if n%3==0 and n%5==0:
    print("FizzBuzz")
elif n%3==0:
    print("Fizz")
elif n%5==0:
    print("Buzz")
else:
    print(n)

9. Password Strength

Commonly asked at Zoho, Freshworks, Amazon & Oracle. Checks whether a password is strong based on length, uppercase, and digit rules.

password=input("Enter Password: ")
has_upper=any(c.isupper() for c in password)
has_digit=any(c.isdigit() for c in password)
if len(password)>=8 and has_upper and has_digit:
    print("Strong Password")
else:
    print("Weak Password")
